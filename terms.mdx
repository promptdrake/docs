## 2. Kebijakan Penggunaan Wajar (Fair Use Policy - FUP)

Seluruh layanan berbasis shared resource (sumber daya bersama) tunduk pada kebijakan penggunaan wajar untuk memastikan stabilitas dan performa optimal bagi seluruh pengguna di node server yang sama.

### A. Pterodactyl Panel (Penggunaan RAM & CPU)

<Warning>
**Batas Penggunaan RAM & CPU**:
Jika Anda membeli paket server dengan alokasi tertentu (misalnya **4 GB RAM**), Anda **TIDAK DIPERBOLEHKAN** menggunakan 100% RAM secara terus-menerus setiap jam (*sustained max usage*) atau melakukan *continuous burst*.
</Warning>

- **RAM / Memori**: Alokasi RAM paket server Anda adalah batas maksimal (*peak limit/headroom*), bukan beban konstan 24/7. Menggunakan RAM mendekati 100% secara nonstop berisiko mengganggu kestabilan node dan server Anda akan otomatis dimatikan oleh sistem (*OOM Killed*).
- **CPU Usage**: Penggunaan CPU rata-rata di atas **85% secara berkelanjutan selama 1 jam** akan dikenakan pembatasan otomatis (*CPU capping/throttling*). Jika penggunaan CPU terus-menerus tinggi dan membebani server bersama, layanan dapat disuspend.
- **Disk I/O**: Penggunaan disk read/write harus dalam batas wajar. Script atau bot yang menyebabkan *IOWait* tinggi secara konstan pada storage NVMe bersama akan dibatasi kecepatannya.

### B. DirectAdmin Web Hosting

- **Penyimpanan (Storage Usage)**: Alokasi penyimpanan hosting **hanya diperuntukkan bagi file website resmi** (HTML, PHP, CSS, JS, database, dan gambar pendukung website). 
  - **Dilarang keras**: Menggunakan hosting sebagai tempat penyimpanan backup eksternal, personal cloud/file-locker, koleksi media pribadi (video/musik), atau file sharing publik.
- **Batas Pengiriman Email**: Pengiriman email dibatasi maksimal **200 email per hari per akun** untuk menjaga reputasi IP mail server dan mencegah indikasi spamming.
- **CPU & Memory Hosting**: Setiap akun hosting memiliki batas cgroups CPU dan RAM. Penggunaan script yang memicu loop tak terbatas atau overload akan dibatasi otomatis oleh sistem.
