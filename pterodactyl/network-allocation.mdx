Setiap server di Aisbir Cloud memiliki alamat IP dan nomor Port khusus agar server atau aplikasi web kamu bisa diakses dari luar.

---

### 1. Melihat Port Server Kamu

1. Buka server kamu di panel, lalu klik menu **Network**.
2. Kamu akan melihat:
   - **IP Alias / Node IP**: Alamat IP server kamu (contoh: `103.xx.xx.xx`).
   - **Port**: Nomor port yang dialokasikan khusus untuk server kamu (contoh: `25565` atau `8080`).
   - **Primary Allocation**: Port utama yang digunakan server.

---

### 2. Cara Setting Port di Kode Script (Node.js / Python / Go)

Agar aplikasi web atau API kamu tidak error saat dinyalakan, pastikan untuk menggunakan variabel port dinamis dari environment server dan listen ke host `0.0.0.0`:

<Tabs>
  <Tab title="Node.js (Express)">
    ```javascript
    const express = require('express');
    const app = express();

    // Mengambil port otomatis dari panel Pterodactyl
    const PORT = process.env.SERVER_PORT || process.env.PORT || 3000;

    app.get('/', (req, res) => {
      res.send('Server Berhasil Berjalan di Aisbir Cloud!');
    });

    app.listen(PORT, '0.0.0.0', () => {
      console.log(`Server aktif di port ${PORT}`);
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import os
    from flask import Flask

    app = Flask(__name__)

    @app.route('/')
    def home():
        return "Server Berhasil Berjalan di Aisbir Cloud!"

    if __name__ == '__main__':
        port = int(os.environ.get("SERVER_PORT", 8080))
        app.run(host='0.0.0.0', port=port)
    ```
  </Tab>
</Tabs>

<Tip>
Jika kamu butuh port tambahan untuk fitur lain (misalnya web dashboard terpisah atau bot multi-service), kamu bisa menghubungi tim bantuan Aisbir Cloud lewat tiket support.
</Tip>
