Menu **Users** memudahkan kamu untuk memberi akses kelola server ke teman atau developer tanpa perlu memberikan email dan password akun utama kamu.

---

### 1. Cara Menambahkan Sub-User Baru

1. Buka server kamu di panel, lalu klik menu **Users**.
2. Klik tombol **New User** di pojok kanan atas.
3. Masukkan **Email** teman kamu yang sudah terdaftar di panel Aisbir Cloud.
4. Centang izin (*permissions*) apa saja yang ingin kamu berikan, misalnya:
   - **Control**: Menyalakan / mematikan server
   - **Files**: Mengedit dan upload file
   - **Console**: Melihat console log
   - **Databases**: Melihat database
5. Klik tombol **Invite User**.

---

### 2. Mengubah atau Menghapus Akses

- **Edit Izin**: Klik ikon pensil (**Edit**) di samping nama subuser, ubah centang izin, lalu klik **Save**.
- **Hapus Akses**: Klik ikon tempat sampah (**Delete**) jika kamu ingin mencabut akses subuser tersebut dari server kamu.

<Tip>
Beri izin sesuai kebutuhan saja. Misalnya, jika developer hanya bertugas mengedit script bot, kamu cukup centang izin **Control** dan **Files**.
</Tip>
