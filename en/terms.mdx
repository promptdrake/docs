## 2. Fair Use Policy (FUP) & Resource Governance

All plans operating on shared infrastructure are subject to our Fair Use Policy to maintain stability and performance for all users sharing the physical host nodes.

### A. Pterodactyl Panel (RAM & CPU Limits)

<Warning>
**RAM & CPU Sustained Usage Limits**:
If you purchase a service with a defined resource allocation (e.g. **4 GB RAM**), you **CANNOT use 100% of the RAM every hour continuously** or maintain an ongoing burst workload.
</Warning>

- **RAM / Memory Allocation**: Your plan's RAM allocation is an upper ceiling (*peak headroom*), not a 24/7 continuous utilization benchmark. Running applications near 100% RAM non-stop risks destabilizing the host node, and the container will automatically be terminated by the kernel (*Out of Memory / OOM Killed*).
- **CPU Usage**: Average CPU usage exceeding **85% sustained over a 1-hour window** will be automatically capped (*CPU throttling*). Persistent CPU overload threatening node performance may result in temporary suspension.
- **Disk I/O**: Disk read/write operations must remain within reasonable thresholds. Scripts or bots causing excessive *IOWait* on shared enterprise NVMe arrays will have their I/O throughput restricted.

### B. DirectAdmin Web Hosting

- **Storage Usage**: Hosting disk allocations are **strictly reserved for legitimate website files** (HTML, PHP, CSS, JS, MySQL databases, and media assets linked directly to your web pages).
  - **Prohibited**: Utilizing hosting space as external backup storage, personal cloud/file-lockers, movie/music sharing hubs, or public download mirrors.
- **Email Rate Limits**: Outbound emails are limited to **200 emails per day per account** to protect mail server IP reputation and eliminate spamming activities.
- **CPU & Memory**: Each hosting account operates under CloudLinux/cgroup thresholds. Scripts causing runaway infinite loops or high server loads will be automatically throttled.
