---

### 1. Select Change Egg in Server Subscription

Log in to the client dashboard, open the **Subscription** tab for your server, and click **Change Egg**.

<Frame caption="Change Egg Option">
  ![Change Egg](https://id-cdn.aisbirnusantara.com/documentation/Screenshot%202026-03-28%20064329.png)
</Frame>

---

### 2. Choose New Environment

Select the environment (egg) you wish to use according to your application or game server requirements (e.g. Node.js, Python, Go, Java, or Minecraft).

<Frame caption="Select Environment">
  ![Select Environment](https://id-cdn.aisbirnusantara.com/documentation/Screenshot%202026-03-28%20064404.png)
</Frame>

---

### ⚠️ Warning

> Changing your **Startup / Environment** will:
> - **Wipe all existing server data**
> - Reset server files and configurations to the default template of the new egg
> - Previous files cannot be recovered automatically
>
> **Always ensure you have downloaded all important files before proceeding.**
