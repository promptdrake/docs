### Supported Runtimes

We support a wide range of modern runtimes to ensure compatibility with your applications out of the box:

- **Node.js** (LTS & Latest)
- **Go (Golang)**
- **Bun Runtime**
- **GraphQL Server Environments**

All runtimes are tuned for low latency and optimal server performance.

### Node.js

Full support for Node.js applications, including:

- Native `npm`, `yarn`, and `pnpm` package managers
- ES Modules (ESM) & CommonJS (CJS)
- WebSocket & HTTP/2 support
- Compatible with Express, Fastify, NestJS, and Koa
- Ideal for Discord bots (discord.js), Telegram bots, and persistent background workers

### Go (Golang)

High-performance native Go binary execution:

- Direct binary execution with minimal memory footprint
- High concurrency support
- Perfect for REST APIs, microservices, and backend daemons

### Bun Runtime

Modern, ultra-fast JavaScript & TypeScript runtime:

- Significantly faster execution and cold start times
- Built-in bundler, test runner, and package manager
- Native TypeScript execution without transpile steps

### Pterodactyl Control Panel

We utilize **Pterodactyl Panel** for intuitive server management:

- Web-based management console
- Real-time CPU, RAM, Disk, and Network monitoring
- Built-in web code editor and file manager
- One-click server power controls (Start / Restart / Stop / Kill)
- Secure, isolated Docker container sandbox

### Infrastructure

- **Locations**: Indonesia & Europe Datacenters
- **Storage**: Enterprise NVMe / SSD arrays
- **Protection**: Multi-layered DDoS protection & high-speed low-latency uplink
